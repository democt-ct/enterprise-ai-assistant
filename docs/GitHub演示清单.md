# GitHub 演示清单

## 推荐截图

1. 首页自然语言入口：展示企业事务发起方式。
2. Case 中心：同时展示任务状态、专家结论和待确认操作。
3. 入职操作提案：IT、法务、财务三个 Proposal。
4. HR 审批视图：展示确认后的 Mock 执行按钮。
5. Case 完成页：4 个任务完成、3 个操作已执行。
6. Trace 或评测终端：展示协作模式、参与专家和评测结果。

截图必须使用 Mock 员工数据，隐藏 API Key、JWT、Cookie、本机路径和完整内部推理。

## 三分钟演示顺序

1. 员工创建“新员工入职协同”并补充日期、岗位、部门。
2. Case Runtime 完成 HR 前置任务，生成 IT、法务、财务任务和 Proposal。
3. 员工确认三个 Proposal，系统只改变状态，不直接执行。
4. 切换 HR 账号，审批并执行 Mock 连接器。
5. 回到 Case 详情，展示任务完成、事件审计和状态收敛。
6. 运行协作策略、Case 安全和 API E2E 三条评测命令。

## GIF 建议

只录制一条完整入职链路，控制在 60–90 秒。不要把聊天、管理后台、全部旧申请页面都录进去，以免稀释 Case 协作主线。
